Project Overview

This portfolio intentionally avoids a framework. The site is built with static markup and small JavaScript renderers that keep content maintainable and easy to extend.

Core Principles

  • Content stays in data files whenever possible.
  • Rendering is handled by lightweight JavaScript at runtime.
  • The homepage, projects page, and resume share the same source of truth.
  • Styling is centralized in a single stylesheet for the main site.

File Responsibilities

  • index.html — homepage content and static sections
  • projects.html — dynamic project detail rendering
  • resume.html — generated resume layout
  • js/projects-data.js — project source of truth
  • js/resume-data.js — resume profile and contact data
  • js/script.js — shared UI, filters, animation, and interactions

The site uses a simple layered structure: HTML structure, CSS tokens/components, and JS data rendering.

That separation makes the portfolio easy to maintain. You can change content in a single data file without reworking layout markup.

Data Flow

Project and resume entries originate in JavaScript arrays and are rendered into each page with shared logic.

Projects

Entries in js/projects-data.js feed the homepage cards, the projects detail page, and the auto-generated resume.

const projects = [
  {
    id: "project-name",
    title: "Project Title",
    summary: "Short summary",
    category: "interactive",
    tech: ["HTML", "CSS", "JavaScript"]
  }
];

Resume

The resume uses js/resume-data.js for profile and education details, while project content is pulled from the shared project array.

Note: Keep the resume data accurate in one place, and the generated pages will remain in sync.

Scripts & Interaction

The shared script file manages common behavior including toggles, scroll updates, reveal effects, and typing animation.

Shared Runtime Behavior

  • Theme toggle persistence with localStorage
  • Scroll progress bar and back-to-top button
  • Reveal animations and active nav linking
  • Hero typing animation with reduced-motion support

Specialized Docs Behavior

js/docs.js powers the docs sidebar and mobile navigation on the documentation pages.

Performance & Layout Stability

The site is optimized around predictable layout rules so pages feel smooth on both desktop and mobile.

Layout Safety

  • Hero and project images reserve space before loading.
  • Longer content is wrapped safely to prevent overflow.
  • Animations defer to reduced-motion preferences.

Fonts & Assets

  • Fonts are preloaded and loaded with fallback handling.
  • Images are lazy-loaded below the fold when appropriate.
  • Critical images use explicit dimensions for stable layout behavior.

Deployment Notes

Because this portfolio is fully static, deployment is straightforward and only depends on hosting the generated files.

Recommended Workflow

  1. Update HTML / data files with the final copy.
  2. Run image optimization when assets change.
  3. Push the repository to GitHub Pages or a static host.
  4. Confirm that links and assets resolve on the deployed domain.
